EXP4 — KELUARGA MODEL SOUP (garis adaptasi; EKSPANSI 2026-07-08)
  Interpolasi bobot θ = α·base + (1−α)·gpl (Wortsman dkk. 2022 model soups;
  WiSE-FT). Nol training. α = 0.5 DIKUNCI DI MUKA (uniform soup): TANPA sweep,
  krn 30 kueri pakar terlalu kecil utk tuning α — sweep lalu pilih terbaik =
  overfit test set.
  Awalnya cuma 1 pasangan (Base ⊕ GPL 10k), tapi per 2026-07-08 diekspansi 
  menjadi keluarga besar utk menguji semua checkpoint adaptasi:
    exp4.0 = Base ⊕ exp0 (GPL 10k awal)
    exp4.1 = Base ⊕ exp1 (GPL 5k)
    exp4.2 = Base ⊕ exp2 (GPL Gemma)
    exp4.3 = Base ⊕ exp3 (BGE Teacher)
  Hipotesis: obat DRIFT — adaptasi merusak kueri base-kuat,
  interpolasi mempertahankan geometri base sambil menyimpan sebagian ketajaman 
  intrinsik GPL.
  Artefak: 8-soup-all.py → models/gpl-exp4.0..4.3-{e5,gte} (+SOUP.txt);
  Orkestrasi: run_exp4_all.sh (resume pasca-OOM: run_exp4_resume.sh).
  Embedding id+en+pli dilakukan untuk seluruh keluarga.

EXP5 — KELUARGA RERANK (KELAS TERPISAH; BUKAN garis adaptasi)

  RQ BEDA: exp0-4 = "bisakah ADAPTASI BOBOT mengalahkan base?" (jawab: TIDAK).
  exp5 = "kalau adaptasi gagal, jalur apa yg menaikkan kualitas retrieval di

  - Varian (dieksekusi batch via run_exp5_all.sh):

    exp5.0    = Reranker di atas exp0 (GPL 10k)

    exp5.2    = Reranker di atas exp2 (Gemma Query-gen)
    exp5.3    = Reranker di atas exp3 (BGE Teacher)
    exp5.4    = Reranker di atas exp4.0 (Model Soup awal)
  - Lawan banding SAH: varian single-stage masing-masing (misal exp5.1 vs exp1).

  - Kenapa bge-reranker-v2-m3:
    (a) XLM-R/M3, teruji MIRACL — bahasa INDONESIA termasuk (Chen dkk. 2024);
    (b) alternatif kalah constraint: LLM-API tak reproducible + tak muat GPU 12GB;

LANDASAN AKADEMIS PEMILIHAN KOMPONEN (resource-constrained tapi principled)
  exp0 = REPLIKASI resep GPL (Wang dkk., NAACL 2022) apa-adanya; tiap komponen
  dipetakan 1:1 ke padanan MULTILINGUAL-nya (korpus id+en), bukan pilihan bebas:
  - Query-gen : GPL memakai doc2query/docTTTTTquery (Nogueira dkk., 2019) ->
    padanan multilingualnya doc2query mT5 mMARCO-14langs (Bonifacio dkk., 2021;
    mencakup bahasa Indonesia).
  - Teacher   : GPL memakai CE ms-marco-MiniLM -> padanannya mmarco-mMiniLMv2
    (dilatih di mMARCO; Bonifacio dkk., 2021).
  - Miner     : GPL memakai dense retriever utk hard-neg -> dipakai e5-base
    (retrieval-native multilingual terkuat yg tersedia; rincian di bawah).
  - Student   : e5-base (Wang dkk., 2024) & gte-multilingual-base (Zhang dkk.,
    2024, mGTE) = model retrieval-native multilingual (REGISTRY, rencana.txt §2).
  Konsekuensi framing: exp0 = "GPL as published"; semua deviasi dari resep asli
  baru terjadi di exp1..exp3, masing-masing SATU variabel.

  Query-gen LLM kecil lokal (gemma2:2b, exp2):
  - InPars (Bonifacio dkk., 2022) & Promptagator (Dai dkk., 2022): kueri sintetis
    dari LLM utk melatih retriever; kualitas kueri > kuantitas.
  - InPars-Light (Boytsov dkk., 2023): LLM OPEN KECIL (~7B) cukup utk query-gen,
    kompetitif vs GPT-3 -> justifikasi memakai model kecil krn resource.
  - doc2query-- (Gospodinov dkk., ECIR 2023): doc2query berhalusinasi/noisy ->
    dasar meninggalkan mT5 doc2query (sejalan sampel junk mT5 kita).
  - UDAPDR (Saad-Falcon dkk., 2023): adaptasi domain hemat-biaya dgn kueri LLM.
  - Model lokal (Ollama) = reproducible (seed tetap, config.GPL_SEED) & tanpa
    ketergantungan API; gemma2:2b muat penuh di GPU 12GB (Gemma Team, 2024).
  Hard-negative miner (GPL_RETRIEVER = multilingual-e5-base, SEMUA exp):
  - ANCE (Xiong dkk., ICLR 2021): hard-neg dari dense retriever >> BM25/random;
    mining dgn model yg dilatih (self-mining) = negatif di batas kemampuan model.
  - GPL (Wang dkk., NAACL 2022): pipeline acuan; miner dense + teacher CE.
  - RocketQA (Qu dkk., NAACL 2021): hard-neg dense berisiko false-negative ->
    di GPL ditangani via margin teacher CE (bukan filter; lihat CATATAN E2).
  - Miner DIKUNCI konstan lintas exp0-exp3 -> variabel terkontrol; bias ke-e5
    (gte dilatih dgn negatif hasil mining e5) diakui, tapi seragam di semua exp
    sehingga tak mencemari perbandingan antar-exp.
  CATATAN KEJUJURAN — hierarki kekuatan landasan (utk bab metodologi):
  exp0 (replikasi, terkuat) > exp3 (arah + pilihan reranker standar + bukti
  probe internal) > exp2 (arah kuat: InPars/Promptagator/UDAPDR; tapi
  INSTANSIASI gemma2:2b = resource-driven — InPars-Light main di kelas ~7B,
  2b dipilih krn muat GPU 12GB). Mitigasi exp2:
  (a) MANIPULATION CHECK: variabel sesungguhnya = "kueri natural & on-topic";
      gemma2 cuma instrumen -> audit kualitas kueri terkuantifikasi
      (sampel buta mT5 vs gemma2) membuktikan instrumen menghasilkan
      treatment yg dimaksud. (Sampel awal 5v5: mT5 4/5 nonsens, gemma2 5/5
      natural — formalisasi menyusul.)
  (b) SCOPE KLAIM: hasil exp2 = uji SATU instansiasi hemat-resource dari
      LLM-query-gen (lower bound), bukan verdict pendekatannya; negatif
      != pendekatan gagal, positif = cukup buktikan faktor kualitas kueri.

  Teacher pseudo-label (exp0-exp2 = mMiniLM; exp3 = ganti ke bge, 1 var):
  - MarginMSE (Hofstaetter dkk., 2020): student di-distilasi dari MARGIN teacher
    CE -> kualitas student DIBATASI kualitas label teacher (distillation ceiling).
    Ganti teacher = intervensi langsung di kualitas supervisi, data tetap beku.
  - RocketQA (Qu dkk., 2021) & RocketQAv2 (Ren dkk., 2021): cross-encoder yang
    lebih kuat -> label/denoising lebih baik utk melatih dense retriever.
  - mMiniLM = CE standar mMARCO (Bonifacio dkk., 2021), dilatih MS MARCO hasil
    TERJEMAHAN MESIN (translationese) + kecil (~118M) -> label berisik di domain
    Buddhis id/en. bge-reranker-v2-m3 (Chen dkk., 2024, ~568M, basis XLM-R/M3)
    unggul di benchmark multilingual (MIRACL dst.).
  - Bukti internal (probe 1000 triple beku, 2026-07-03): margin mMiniLM vs bge
    r=.77, sign-agreement 83.5%; pada 16.5% kasus beda-ordering, 55% adalah bge
    "abstain" (|margin|<0.1 std) di kueri sampah yang mMiniLM nilai pede
    (|margin| s.d. 3.6 std) -> mekanisme yang diuji exp3 = KALIBRASI label
    (peredam noise), bukan sekadar pembalik ordering.
