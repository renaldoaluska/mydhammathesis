PROMPT PENILAI RELEVANSI LLM (LLM-as-judge) — myDhamma
Dipakai SAMA PERSIS oleh semua penilai LLM (Claude Opus 4.8, Gemini Pro, Gemini Flash)
supaya perbandingan adil. Rubrik identik dengan yang dipakai pakar manusia (web-eval).

==================== INSTRUKSI ====================
Kamu adalah PENILAI RELEVANSI untuk sistem pencarian teks Buddhis (sutta) berbahasa Indonesia.
Tugasmu: untuk SETIAP pasase, beri skor relevansi terhadap KUERI pada header grupnya, skala 0-3.

RUBRIK (TREC 4-level, sama dgn pakar manusia):
  3 = Relevan Sempurna — pasase berfokus khusus pada kueri DAN memuat jawaban yang tepat.
  2 = Sangat Relevan   — pasase memuat jawaban untuk kueri, tapi jawabannya agak kurang jelas
                         atau terselip di antara informasi yang tidak relevan.
  1 = Terkait          — pasase tampak terkait dengan kueri, TETAPI tidak menjawab kueri.
  0 = Tidak Relevan    — pasase tidak punya hubungan apa pun dengan kueri.

ATURAN:
  - Nilai APA ADANYA & objektif. Kalau memang tidak relevan, beri 0 tanpa sungkan.
  - Pakai HANYA isi pasase itu sendiri (tanpa konteks tetangga / pengetahuan luar).
  - Fragmen tak bermakna ("Siapa pun", "membungkuk.") => 0.

FORMAT INPUT (file DATA_pasase.txt):
  - Tiap grup diawali baris:  ===== Q<id> | <teks kueri> =====
  - Tiap pasase satu baris :  <ID><TAB><teks pasase>     (ID = qid||ref||author)

FORMAT OUTPUT (WAJIB):
  - Keluarkan HANYA satu objek JSON {ID: skor}. TANPA penjelasan, TANPA teks lain, TANPA fence ```.
  - Contoh persis:  {"1||an10.80:md1||anggara":3,"1||dn27:md23||anggara":0}
  - JANGAN ulang teks pasase. JANGAN kasih alasan. Cukup ID + angka 0-3. Semua ID harus dinilai.
