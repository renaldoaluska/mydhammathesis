4. LOGIKA APP: MODEL KECIL vs BESAR
--------------------------------------------------------------------------------
Di app.py, model kecil masuk daftar _SMALL_CHAT_MODELS:
  gemma3:4b, gemma3:1b, gemma2:2b, llama3.2:1b, llama3.2:3b

gemma2:9b TIDAK masuk daftar itu → dianggap model besar.

Dampaknya:

  Model KECIL (gemma3:4b):
  - Query craft LLM dimatikan → pencarian pakai query mentah user.
  - LLM kecil sering gagal output SKIP_SEARCH / merusak kueri semantik
    (contoh: suntik "sutta", "kutipan", atau istilah Sanskerta).
  - Regex rule-based tetap menangkap sapaan umum (halo, makasih, dll).

  Model BESAR (gemma2:9b):
  - Query craft LLM aktif → LLM merapikan kueri sebelum retrieval.
  - Lebih patuh instruksi SKIP_SEARCH & identitas myDhamma AI.
  - Inference sedikit lebih lambat, RAM lebih besar.

Catatan simulasi:
  - Untuk sapaan ("halo", "makasih"), gemma3:4b gagal di LLM tapi di app
    nyata tetap aman karena regex _SKIP_PATTERNS menangkap sebelum LLM dipanggil.
  - Keduanya masih gagal strip meta-word ("sutta"/"kutipan") pada query rewrite;
    itu isu prompt, bukan sekadar ukuran model.
  - gemma3:4b di produksi lebih buruk untuk retrieval karena query craft off
    → kirim string mentah "kutipin sutta tentang penderitaan dong" ke retriever.

--------------------------------------------------------------------------------
6. KEPUTUSAN
--------------------------------------------------------------------------------
Default chat dipilih: gemma2:9b

Alasan (berdasarkan simulasi + logika app):
  1. Query craft aktif (gemma3:4b mem-bypass LLM rewrite).
  2. Lebih patuh SKIP_SEARCH & deteksi identitas di uji LLM langsung.
  3. Kualitas RAG setara; latency sedikit lebih tinggi (~+2s) masih acceptable.
  4. Ukuran 9B masuk kategori "model besar" menurut _query_craft_ok().

Trade-off diterima:
  - Lebih lambat & boros RAM vs gemma3:4b.
  - Query meta-strip belum sempurna di kedua model (perlu perbaikan prompt).

Alternatif jika gemma2:9b terlalu berat:
  • qwen3:8b (8.2B, sudah ter-pull) — uji dulu sebelum switch.
  • gemma3:4b — hanya untuk dev/cepat jalan; query craft off.
