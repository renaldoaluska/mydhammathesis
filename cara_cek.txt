====================================================================
PANDUAN MANAJEMEN APLIKASI SERVER (SYSTEMD)
====================================================================
Bye-bye tmux. Semua aplikasi sekarang jalan otomatis di background.

--------------------------------------------------------------------
1. PERINTAH SEHARI-HARI (RESTART, STOP, STATUS)
--------------------------------------------------------------------
Kalau habis merubah kode (misal app.py) atau config, WAJIB direstart.

- Web Utama:      systemctl --user restart mydhamma-web
- Web Eval:       systemctl --user restart mydhamma-eval
- Tunnel CF:      systemctl --user restart cloudflared

>> GRACEFUL RELOAD (tanpa downtime) — kapan boleh, kapan TIDAK:
   - Ngedit prompts.json saja  -> TIDAK perlu restart sama sekali.
     get_prompts() di app.py auto-reload via cek mtime tiap request.
   - Ngedit KODE app.py        -> WAJIB restart penuh (perintah di atas).
     JANGAN andalkan "kill -HUP" / "systemctl reload": karena gunicorn
     pakai flag --preload, app sudah di-import master SEBELUM fork, jadi
     HUP cuma fork ulang worker dari memori LAMA -> perubahan app.py TIDAK
     kebaca. Satu-satunya cara kode app.py kepakai = restart penuh.
   - Mau zero-downtime betulan utk kode? Hot-upgrade master gunicorn:
       kill -USR2 <PID_MASTER>     # spawn master+worker baru di samping
       kill -WINCH <PID_MASTER>    # matikan worker master lama (graceful)
       kill -TERM  <PID_MASTER>    # matikan master lama setelah yakin OK
     (PID master = `systemctl --user show -p MainPID mydhamma-web`)
     Tapi utk dev biasa, `systemctl --user restart` jauh lebih simpel.

Cek Status (Hijau = Aman, Merah = Mati/Error):
- systemctl --user status mydhamma-web
- systemctl --user status mydhamma-eval
- systemctl --user status cloudflared

Matikan Aplikasi (Stop sementara):
- systemctl --user stop mydhamma-web

--------------------------------------------------------------------
2. CARA MELIHAT LOG ERROR (PENGGANTI `tmux attach`)
--------------------------------------------------------------------
Untuk melihat log error, print Python, atau traffic secara LIVE / 
real-time (tekan Ctrl+C untuk keluar dari tampilan log):

- Log Web Utama:  journalctl --user -u mydhamma-web -f
- Log Web Eval:   journalctl --user -u mydhamma-eval -f
- Log Tunnel:     journalctl --user -u cloudflared -f

*Catatan: 
- Hilangkan huruf "-f" di belakang kalau cuma mau baca log lama.
- Tambahkan "-n 50" (contoh: journalctl --user -u mydhamma-web -n 50 -f) 
  untuk langsung melihat 50 baris terakhir biar ga kepanjangan.

--------------------------------------------------------------------
3. SETUP LINGER (AGAR SERVER TIDAK MATI SAAT TERMINAL DITUTUP)
--------------------------------------------------------------------
Cukup dijalankan 1x seumur hidup untuk akun paps21. Ini yang bikin 
aplikasi tetap hidup walaupun koneksi SSH diputus.

- Nyalakan Linger:   loginctl enable-linger paps21
- Cek Status Linger: loginctl show-user paps21 | grep Linger
  (Kalau hasilnya "Linger=yes", berarti aman ditinggal tidur)

--------------------------------------------------------------------
4. CARA EDIT CONFIG SYSTEMD (NANO) & SETUP GUNICORN / AUTO-RESTART
--------------------------------------------------------------------
Kalau mau ngedit file service (misal aplikasi mati terus, butuh auto-restart, 
atau ganti port), atur filenya pakai Nano.

1. Buka file config:
   - Web Utama: nano ~/.config/systemd/user/mydhamma-web.service
   - Web Eval:  nano ~/.config/systemd/user/mydhamma-eval.service
   - Tunnel CF: nano ~/.config/systemd/user/cloudflared.service

2. Aturan Wajib di dalam file (biar kuat & prod-ready):
   - Di bawah [Unit], pastikan ada:
     StartLimitIntervalSec=0
   
   - Di bawah [Service], pastikan ada:
     Restart=always
     RestartSec=5
   
   - Khusus Web Utama & Eval, bagian ExecStart WAJIB pakai gunicorn
     dengan setingan 1 worker, preload, dan timeout 120 (anti-lemot):

     > ExecStart Web UTAMA (Port 5002, file app.py):
     ExecStart=/home/paps21/palisemantic5026221144/venv/bin/gunicorn -w 1 --preload --timeout 120 -b 127.0.0.1:5002 app:app

     > ExecStart Web EVAL (Port 5001, file eval_app.py):
     ExecStart=/home/paps21/palisemantic5026221144/venv/bin/gunicorn -w 1 --preload --timeout 120 -b 127.0.0.1:5001 eval_app:app

3. Cara Save di Nano:
   - Pencet Ctrl + X
   - Ketik Y
   - Pencet Enter

--------------------------------------------------------------------
5. DAEMON-RELOAD (WAJIB SETELAH NGEDIT FILE DI ATAS)
--------------------------------------------------------------------
Systemd tidak akan sadar ada perubahan kalau belum di-reload.
Setiap kali selesai ngedit pakai Nano, WAJIB jalankan 2 perintah ini:

1. Refresh sistem:
   systemctl --user daemon-reload

2. Restart aplikasi yang bersangkutan:
   systemctl --user restart mydhamma-web
   (Ganti nama service di belakang sesuai yang baru saja diedit)
