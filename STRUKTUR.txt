------------------------------------------------------------
PRINSIP STRUKTUR
------------------------------------------------------------
- TANPA penomoran "tahap" (1-pertama/2-kedua). Itu artifact sejarah dhammakathika
  (fase TSDAE lalu GPL). Repo ini mulai bersih dengan SATU metode final (GPL),
  jadi dikotomi pilot-vs-final cukup diceritakan di laporan TA, bukan di folder.
- PAKAI penomoran URUTAN PIPELINE (1->5): menandai urutan eksekusi.
- KONVENSI: folder BERNOMOR = langkah pipeline (urut dieksekusi); folder/file
  TANPA nomor = utility/shared lintas-langkah (config.py, sync-hf/, web/).
- EKSPLOR SUDAH MENCAKUP ANALISIS: bagian 2-eksplor tidak hanya statistik
  deskriptif, tapi juga ANALISIS yang menjadi JUSTIFIKASI desain chunk baru
  (heading bocor, giant chunk dari <p> tak tertutup, junk, h4-h6/<td> ter-drop).
  -> folder "audit-korpus" terpisah TIDAK ADA lagi; fungsinya melebur ke eksplor.
- output/ MIRROR code/ (prinsip dari dhammakathika): tiap langkah punya folder
  output bernama sama.
- config.py = SATU sumber kebenaran (registry model + path + komponen GPL).
  Tambah/ubah model cukup di sini; file lain mengikuti. (NO redundansi.)
- Lane web dipisah (folder web/) karena berjalan paralel (model-agnostic).
- SERVER vs LOKAL: pipeline berat (training/encode) jalan di SERVER KAMPUS (GPU).
  Artefak besar di-PUSH ke HF Hub, lalu bisa di-PULL ke PC lokal (mis. untuk
  menjalankan web tanpa GPU). Lihat sync-hf/.

ISI TIAP LANGKAH (rencana file .py)
------------------------------------------------------------
config.py
    REGISTRY model (e5-base, gte-base, LaBSE, BM25) + lang_mode + needs_prefix,
    PATH dasar (raw, output per-langkah), KOMPONEN GPL (query-gen, cross-encoder).

1-get-data/
    _sc.py                : helper git sparse-checkout (dipakai skrip 1-5, no redundan)
    1-get-sc-bilara.py    : unduh PLI(root) + EN(translation) + sec(html struktur)
    2-get-sc-htmltext.py  : unduh terjemahan HTML (ID + EN non-bilara)
    3-get-sc-name.py      : nama sutta
    4-get-sc-tree.py      : hierarki nikaya (browse tree)
    5-get-sc-info.py      : author_edition.json (atribusi penerjemah)
    6-get-base-models.py  : unduh & pin base model (e5, gte, LaBSE)

2-eksplor/  (= eksplorasi + ANALISIS justifikasi; _load.py = iterator chunk bersama)
    1-parameter.py        : ukuran (param) tiap model -> feasibility GPU
    2-hierarki.py         : struktur korpus mentah (sumber/bahasa/pitaka)
    3-statistik.py        : distribusi dokumen/chunk & panjang char/kata per bahasa
    4-analisis-chunk.py   : ANALISIS justifikasi chunk (heading h1-h6, junk, giant-chunk)
    5-panjang.py          : panjang token per tokenizer -> justifikasi max_seq

3-praproses/
    1-chunk.py            : chunking full Tipitaka (bilara + html_text), lxml,
                            heading-tagged, parts, double-BR; +buang junk murni.
                            (TANPA min-length: teks suci sengaja utuh.)

4-training/  (GPL; _gpl.py = path/IO/loader pasase Sutta + prefix e5)
    1-query-gen.py        : generate kueri sintetis (mT5) per pasase -> (q, P+)
    2-hard-neg.py         : hard negative mining (dense retriever) -> (q, P+, P-)
    3-pseudo-label.py     : cross-encoder margin = CE(q,P+) - CE(q,P-)
    4-train-marginmse.py  : fine-tune model finalis (MarginMSE)
    (komponen mT5 & cross-encoder multilingual: lihat rencana.txt TODO)

5-eval/
    common.py             : loader anotasi, dedup, skala 0-3, util (reuse)
    1-precompute.py       : precompute hasil retrieval per kueri (cache)
    2-intrinsic.py        : gap cosine intra/inter (dev set, tuning GPL)
    3-ndcg.py             : nDCG@10 (utama) + nDCG@5
    4-precision.py        : P@10 + MRR@10 (relevan = grade>=2)
    5-spearman.py         : Spearman rho (sekunder, kalibrasi cosine<->grade)
    6-iaa.py              : Inter-Annotator Agreement (eval-2/3, >=2 pakar)

sync-hf/
    1-push-hf.py          : upload model + embeddings + cache ke HF Hub
                            (flag: --m model, --e embeddings, --c cache, --a all)
    2-pull-hf.py          : download artefak dari HF Hub (flag sama) -> jalan di lokal

web/
    aplikasi eval (modul asesmen pakar GRA + link SUS ke Gform https://forms.gle/Xqt75xXesjgN1ajk6)
    aplikasi myDhamma (search + reader).

                                 + .../2-kedua/4-analisis/1-audit-korpus.py (analisis)
                (digabung jadi statistik + analisis justifikasi chunk)

                (sudah lxml/heading-tag/parts/double-BR. TAMBAH: buang junk murni.
                 JANGAN pasang min-length: teks suci sengaja utuh.)
4-training    : BARU (GPL)
                (TSDAE & contrastive lama DIBUANG.)
5-eval        : REUSE sebagian  <- dhammakathika .../1-pertama/3-eval/* + extrinsic_common.py
                (skala 0-3 dipertahankan; SESUAIKAN: pool top-10, utama nDCG@10;
                 +6-iaa.py mengacu .../2-kedua/3-eval/3-eval-iaa.py)
